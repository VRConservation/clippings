# Geospatial

**Summary**: GIS analysis, GDAL/OGR tools, and ArcGIS Pro workflows for geospatial data processing and climate resilience mapping.
**Last updated**: 10-05-2026.

---

- [City2Graph: Geospatial Graphs for Network Analysis and GNNs](https://city2graph.net/latest/): Python library that turns geospatial data into analysis-ready graphs and converts the same graph between GeoPandas, NetworkX, PyTorch Geometric `Data`/`HeteroData`, and rustworkx. Builders cover urban morphology (buildings + street segments + tessellation within a walking distance), GTFS travel-time graphs, OD matrices, and proximity/contiguity graphs (KNN, Delaunay, Gilbert, Waxman, Queen), plus `add_metapaths` to materialize composite relations for heterogeneous GNNs. Reads Overture Maps, OSM-derived data, GTFS/GBFS directly; PyTorch is optional. Peer-reviewed in *Computers, Environment and Urban Systems* 130:102492 (2026). Related: [[Software]], [[Remote_Sensing]]. Keywords: graph neural networks, heterogeneous graphs, network analysis, NetworkX, PyTorch Geometric, GeoPandas, GTFS, Overture Maps, OSMnx, urban morphology
- [Exploring multidimensional Zarr datasets with a 3D forecast cube and SQL](https://gjoremilevski.com/posts/zarr-sql-views/): Visual analytics experiment combining spatial and temporal dimensions in one 3D forecast cube — Zarrita runs in a web worker to fetch and decode the Zarr chunks covering the selected region, values are passed as Arrow batches to DuckDB-WASM, and a SQL view exposes lat/lon and forecast hour so cell selections (`value > 28 AND forecast_hour BETWEEN 24 AND 72`) come back as `cell_id`s. Those ids become a mask texture on a custom deck.gl volume layer, so selections stay live while slicing the cube. Demos use ECMWF AIFS forecasts from dynamical.org. Related: [[Software]], [[Remote_Sensing]]. Keywords: Zarr, deck.gl, DuckDB-WASM, Arrow, web worker, GPU texture, ECMWF AIFS, forecast cube, multidimensional data
- [Mapping and classification of trees outside forests using deep learning](https://www.sciencedirect.com/science/article/pii/S2666017226001483): Lucas et al. in *Science of Remote Sensing* — first multiclass deep-learning mapping of Trees Outside Forests (Forest / Patch / Linear / Tree by FAO area, width, and elongation thresholds) from 20 cm RGB orthophotos across four 100 km² German study areas (Schleswig-Holstein, Brandenburg, NRW north and south). Benchmarks six encoder–decoder architectures: FT-UNetFormer wins (mIoU 0.739, mF1 0.843) and plain U-Net is clearly worst (0.484); transformers beat CNN counterparts and matter most on the structurally hard Patch class. Ablation: nDSM adds +4.4% mIoU, near-infrared adds nothing. Spatial generalization holds up for Forest but degrades sharply for TOF classes, so training data from structurally similar landscapes is essential. Overlaps Copernicus SWF only 26.9% (Linear) and 5.0% (Patch). Code: [TOFMapper](https://github.com/Moerizzy/TOFMapper). Related: [[Forest]], [[Remote_Sensing]], [[Geospatial]]. Keywords: trees outside forests, hedgerows, agroforestry, vision transformers, semantic segmentation, orthophotos, nDSM, coppiced woodland, landscape structure
- [Synthetic Aperture Radar Drone Gets Interferometric Imaging](https://hackaday.com/2026/09/28/synthetic-aperture-radar-drone-gets-interferometric-imaging/): Follow-up on Henrik Forstén's DIY SAR drone. The original build's weak point was GPS at ~1 m; switching to RTK/PPK positioning (fixed ground station corrections in flight, or post-processed against recorded signals) gives centimetre-level trajectory, which is most of why the new autofocus algorithm cleans up the imagery. Also stabilizes the phase-locked loop driving the frequency sweep, adds a fast compression routine to work around the FPGA SD-card bandwidth, and flies the same path twice at two altitudes so phase differences between passes yield an interferogram — an actual elevation map, replacing the constant-elevation assumption that made tall objects lean toward the radar. Related: [[Remote_Sensing]], [[Software]]. Keywords: synthetic aperture radar, SAR, interferometry, RTK, PPK, autofocus, FPGA, elevation mapping, drone, DIY radar
- [From Machine Learning to Large-Scale EO Products](https://ghjuliasialelli.github.io/ML-EO-Maps/): Open online textbook (Sialelli et al., © 2026 IEEE) tracing the whole pipeline from raw satellite data to a published, validated map — six themes covering the EO data landscape, preprocessing (cloud masking, SAR), ML dataset construction and model design, uncertainty quantification, tiled map production and cloud-native dissemination, and design-based accuracy assessment, plus appendices on Sentinel-1 gaps, radiometric terrain correction, and Sentinel-2 cloud masking. My take: good for theory, not practice. Related: [[Remote_Sensing]], [[Software]]. Keywords: Earth observation, machine learning, uncertainty quantification, map validation, accuracy assessment, Sentinel-1, Sentinel-2, cloud masking, SAR
- [A1 Collision Density, 2000–2024](https://visquill.com/gallery/uk-a1/): Interactive visualization mapping 25 years of reported road-traffic collisions along the A1 (London–Edinburgh) from UK DfT STATS19 data — collisions projected onto a reference polyline and aggregated per segment into a density histogram, built with VisQuill and MapLibre GL JS. Related: [[Geospatial]]. Keywords: collision density, road safety, STATS19, UK, A1, MapLibre, data visualization
- [Global WPS LULC Static Data: ESA WorldCover 2021 (USGS 24-category, 3 arc-sec)](https://zenodo.org/records/22674626): Updated 2021 global land-use field for the WRF model — ESA WorldCover 2021 v200 cross-mapped by majority vote to the standard USGS 24-category scheme at ~90 m, replacing default 1992-era data; enables genuine fractional land use and improves Noah-MP surface physics (1.5 GB download, includes GEOGRID.TBL). Related: [[Geospatial]], [[Remote_Sensing]]. Keywords: WRF, land use, ESA WorldCover, LULC, Noah-MP, geogrid, 3 arc-second, USGS classification
- [Mastering GDAL Tools (Full Course)](https://courses.spatialthoughts.com/gdal-tools.html): Comprehensive course on GDAL/OGR command-line utilities covering raster merging, format conversion, compression, COG creation, DEM hillshade, satellite band composites, NDVI, pan-sharpening, WMS layers, georeferencing, vector ETL pipelines, spatial queries, and batch processing. Related: [[Remote_Sensing]], [[Software]]. Keywords: GDAL, OGR, raster processing, vector ETL, GeoTIFF, COG, geospatial CLI, command-line GIS
- [Customize a climate resilience index](https://learn.arcgis.com/en/projects/customize-a-climate-resilience-index/): Build a heat risk index with ArcGIS Pro's Calculate Composite Index tool, combining surface temperature, tree canopy, and population density to target tree-planting for extreme-heat mitigation. Related: [[Geospatial]], [[Remote_Sensing]]. Keywords: ArcGIS, composite index, heat risk, climate resilience, urban planning
- [ArcGIS Pro documentation — NDVI](https://doc.esri.com/en/arcgis-pro/latest/arcpy/spatial-analyst/ndvi.html): The `arcpy.sa.NDVI` function computes the Normalized Difference Vegetation Index from red and NIR bands of a multiband raster. Related: [[Geospatial]], [[Remote_Sensing]]. Keywords: ArcGIS Pro, NDVI, vegetation index, arcpy, raster
